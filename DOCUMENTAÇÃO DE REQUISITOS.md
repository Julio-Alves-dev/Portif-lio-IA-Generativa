# 1. VISÃO GERAL

O projeto **AI GEN PROG — PLAYER EDITION** consiste em um portfólio web desenvolvido para apresentar a trajetória acadêmica, os conhecimentos técnicos, as tecnologias estudadas e os projetos relacionados à formação em **IA Generativa Aplicada à Programação — ChatGPT**, realizada no **SENAI Ary Torres**.

A aplicação possui uma interface visual inspirada em ambientes tecnológicos, inteligência artificial, programação e sistemas digitais, utilizando uma abordagem visual denominada *Player Edition*.

O sistema foi projetado para funcionar como uma apresentação digital da formação do aluno, permitindo que visitantes conheçam rapidamente:

* A formação realizada;
* A carga horária;
* As áreas de conhecimento estudadas;
* As tecnologias utilizadas;
* Os projetos desenvolvidos;
* A experiência prática adquirida;
* A stack tecnológica;
* As informações acadêmicas.

# 2. OBJETIVO DO PROJETO

O objetivo principal é desenvolver um portfólio digital moderno e responsivo capaz de apresentar, de maneira visual e organizada, os conhecimentos adquiridos durante o curso de IA Generativa aplicada à programação.

## 2.1 Objetivos específicos

O sistema deverá:

1. Apresentar a formação acadêmica relacionada à Inteligência Artificial.
2. Destacar a instituição SENAI Ary Torres.
3. Apresentar a carga horária de 44 horas.
4. Apresentar as principais áreas de conhecimento estudadas.
5. Apresentar projetos práticos relacionados ao curso.
6. Apresentar as principais tecnologias utilizadas.
7. Demonstrar a aplicação prática dos conhecimentos.
8. Permitir navegação rápida entre as seções.
